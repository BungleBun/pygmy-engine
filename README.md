# Pygmy Engine
Pygmy engine is a small, text based game engine created entirely in base python. 

# What does this project do/plan to do?

Pygmy is a game engine that can be used to create a wide range of games that run just within a user's terminal just by using a JSON file. 

The engine is open source with great documentation in the making. But just in case the base capabilities of the engine doesn't do everything you want to do with your game, the game engine accepts any user-base created plugins and runs them as if it was the actual source code. Thus, creating an ever expansive engine.

Named after the pygmy python (for obvious reasons), this engine was made for 3 main purposes:

* 1. To keep gaming and game development alike sweet, small, and simple. No exclusive launchers needed to play and no code needed to create.

* 2. To display the capabilities of base python and how amazing the language can be, even without external libraries. 

* 3. To create a tool to inspire and encourage others to create with nothing but a terminal and the wonders of an artistic mind!
